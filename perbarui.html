    3. Simpan ke dashboard

    Dashboard membaca dua file di folder data: mapdata.js dan dashdata.js. Ganti keduanya dengan versi baru.

      Langkah tiap bulan

      1. Terima dua file dari pusat: Pipeline dan Merchant LVM. Tidak perlu diubah atau dirapikan.
      2. Masukkan keduanya di langkah 1, lalu klik Proses data.
      3. Baca pesan di langkah 2. Kalau ada unit mikro baru, pilih kecamatannya.
      4. Cek tabel angka utama. Selisih yang terlalu besar biasanya berarti file salah bulan.
      5. Klik Simpan langsung ke folder data (Chrome/Edge) dan pilih folder data, atau Unduh dua file lalu timpa file lama di folder data.
      6. Buka ulang dashboard. Tanggal di kepala halaman ikut berganti.

      Perlu diketahui

      Data BPS (setahun sekali)

      Pakai format yang sama dengan peta_peluang_semua_wilayah_lengkap.xlsx: satu sheet per kab/kota (nama sheet mis. Kab Bogor, Kota Depok), kolom Kecamatan, Penduduk …, dan opsional Minimarket …. Kab/kota lain bisa ditambah dengan sheet baru.

      Yang dihitung ulang otomatis

      Debitur per kecamatan, kategori dan skor peluang (relatif di dalam tiap kab/kota), status merchant ("Aktif, turun" = transaksi 30 hari turun lebih dari separuh), wilayah merchant dari alamat, dan 120 target kunjungan per kota.

      Keamanan data

      File pusat berisi NIK dan nomor HP. Halaman ini membacanya di browser saja. Yang disimpan ke dashboard hanya nama depan debitur + inisial, tanpa NIK, nomor HP, atau nomor rekening.
